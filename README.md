# AI Kids Invitation

An animated birthday invitation built with AI agents; the full guide is coming.

## Development

```sh
npm install
npm run dev      # local dev server at localhost:4321
npm run build    # production build to ./dist/
npm run preview  # preview the production build locally
```

## OG Image

Regenerate the 1200x630 WhatsApp preview image:

```sh
node scripts/generate-og.mjs
```
