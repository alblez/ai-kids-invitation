# Parents' guide

How this invitation was built with AI agents, and how you can make one for your own child.

## Reading order

1. **[The process](1-the-process.md)** — How the project was organized: ideation, roadmaps, image generation, validation, and delivery. Which AI models did what, how long it took, and the pitfalls you will hit.

2. **[Make it yours](2-make-it-yours.md)** — Exact files and fields to change: child name, party details, WhatsApp number, images, OG preview, deployment. Privacy checklist before you publish.

3. **[Prompts](3-prompts.md)** — Copy-ready prompts for each stage: ideation, roadmap writing, image generation, image validation, stage handoffs, and project review. Generalized with placeholder slots so you can fill in your own details.

4. **[Images with Qwen](4-images-with-qwen.md)** — Why images were generated locally (your child's photos never leave your computer), how to install and run the local image tool, the workflow from reference sheet through final web derivatives, and what to expect in terms of speed and quality.

5. **[Image validation](5-image-validation.md)** — The checks that were run on every generated image, what each one caught, how face landmarks and hand anatomy were verified, and the approval workflow that kept a human in the loop.
